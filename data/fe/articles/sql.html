Три группы команд

  • DDL (データ定義言語): CREATE, ALTER, DROP;
  • DML (データ操作言語): SELECT, INSERT, UPDATE, DELETE;
  • DCL (データ制御言語): GRANT, REVOKE, COMMIT, ROLLBACK.

SELECT

SELECT 列 [, 列 …]
FROM 表
WHERE 条件
GROUP BY 列
HAVING 集計条件
ORDER BY 列 [ASC | DESC]

Порядок выполнения отличается от порядка записи: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY. Отсюда правило: в WHERE нельзя использовать агрегатные функции и псевдонимы из SELECT, а в HAVING — можно агрегаты.

Условия в WHERE

ЗаписьСмысл
BETWEEN a AND bвключительно с обеих сторон
IN (…)входит в список
LIKE '東京%'шаблон: % — любая строка, _ — один символ
IS NULLпроверка на NULL; = NULL не работает
EXISTS (подзапрос)подзапрос вернул хотя бы одну строку
NULL — не значение, а его отсутствие. Любое сравнение с NULL даёт «неизвестно», поэтому строки с NULL не попадают ни в = 5, ни в <> 5. Агрегатные функции (кроме COUNT(*)) NULL игнорируют.

Агрегаты и группировка

COUNT, SUM, AVG, MAX, MIN. COUNT(*) считает строки, COUNT(столбец) — непустые значения, COUNT(DISTINCT столбец) — различные значения.

SELECT 部署コード, COUNT(*) AS 人数, AVG(給与) AS 平均給与
FROM 社員
WHERE 入社年 >= 2020
GROUP BY 部署コード
HAVING COUNT(*) >= 5
ORDER BY 平均給与 DESC

ВидЧто возвращает

LEFT OUTER JOIN (左外部結合)все строки левой таблицы, несовпавшие дополняются NULL
RIGHT OUTER JOINто же для правой
FULL OUTER JOINвсе строки обеих таблиц

SELECT 社員.氏名, 部署.部署名
FROM 社員 INNER JOIN 部署
  ON 社員.部署コード = 部署.部署コード

Самосоединение (自己結合) — таблица соединяется сама с собой через псевдонимы, например, чтобы найти сотрудника и его руководителя.

Подзапросы

Некоррелированный выполняется один раз:

SELECT 氏名 FROM 社員
WHERE 給与 > (SELECT AVG(給与) FROM 社員)

Коррелированный ссылается на внешний запрос и вычисляется для каждой строки — обычно медленнее:

SELECT 氏名 FROM 社員 AS S
WHERE 給与 > (SELECT AVG(給与) FROM 社員 WHERE 部署コード = S.部署コード)

Операции над результатами: UNION (объединение без дублей), UNION ALL (с дублями), INTERSECT, EXCEPT.

Изменение данных

INSERT INTO 社員 (社員番号, 氏名, 給与) VALUES (1001, '田中', 300000)
UPDATE 社員 SET 給与 = 給与 * 1.05 WHERE 部署コード = 'D01'
DELETE FROM 社員 WHERE 退職日 IS NOT NULL

DELETE удаляет строки и журналируется; TRUNCATE быстро очищает таблицу целиком; DROP TABLE удаляет саму таблицу.

Определение структуры

CREATE TABLE 部署 (
  部署コード CHAR(3) NOT NULL,
  部署名     VARCHAR(40) NOT NULL,
  PRIMARY KEY (部署コード)
)

CREATE TABLE 社員 (
  社員番号   INTEGER NOT NULL,
  氏名       VARCHAR(40) NOT NULL,
  部署コード CHAR(3),
  給与       DECIMAL(10,2) DEFAULT 0,
  PRIMARY KEY (社員番号),
  FOREIGN KEY (部署コード) REFERENCES 部署(部署コード)
)

Ограничения: NOT NULL, UNIQUE, CHECK, DEFAULT, PRIMARY KEY, FOREIGN KEY.

Представления и права

Представление (ビュー) — сохранённый запрос, который выглядит как таблица. Скрывает сложность и ограничивает видимые столбцы, то есть работает и как средство защиты. Обновляемость представления ограничена (нельзя обновлять агрегаты и соединения в общем случае).

CREATE VIEW 営業部社員 AS
  SELECT 社員番号, 氏名 FROM 社員 WHERE 部署コード = 'D01'

GRANT SELECT, UPDATE ON 社員 TO 田中
REVOKE UPDATE ON 社員 FROM 田中
