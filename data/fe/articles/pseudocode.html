Зачем нужен псевдокод

В части 科目B задачи по алгоритмам написаны на специальной нотации 擬似言語 (giji gengo, «псевдоязык»). Это не настоящий язык программирования: IPA придумала её, чтобы задания не зависели от знания Java или Python. Спецификация публикуется вместе с заданиями, но на экзамене читать её некогда — нотацию нужно знать заранее.

Основные конструкции

ЗаписьСмысл
○ 手続名(型: 引数)Объявление процедуры или функции. ○ означает начало определения
型名: 変数名Объявление переменной, например 整数型: i — целое i
←Присваивание: x ← 1
/* … */ или //Комментарий
if / elseif / else / endifВетвление
while (условие) … endwhileЦикл с предусловием
do … while (условие)Цикл с постусловием
for (i を 1 から n まで 1 ずつ増やす) … endforЦикл со счётчиком
return 値Возврат значения

Типы

  • 整数型 — целое, 実数型 — вещественное;
  • 論理型 — логический (true / false);
  • 文字型 — символ, 文字列型 — строка;
  • 整数型の配列 — массив целых, 整数型の二次元配列 — двумерный массив;
  • クラス и メンバ встречаются в объектных задачах.
Ловушка с индексами. В псевдокоде IPA массивы индексируются с единицы: у массива A из n элементов это A[1] … A[n]. Запись A[i] の要素数 означает количество элементов.

Операции

сравнение: =, ≠, >, ≥, <, ≤ логические: and, or, not арифметика: +, −, ×, ÷, mod (остаток)

Деление ÷ для целых даёт целую часть, остаток берётся через mod. Конкатенация строк обычно записывается как функция, а не оператором.

Пример задания

○整数型: findMax(整数型の配列: data)
  整数型: i, max
  max ← data[1]
  for (i を 2 から data の要素数 まで 1 ずつ増やす)
    if (data[i] > max)
      max ← data[i]
    endif
  endfor
  return max

Такой фрагмент сопровождается вопросом вида «какое значение вернёт вызов findMax({3, 9, 2, 9})» или «что нужно вписать в пропуск [ a ]».

Как решать

  1. Сначала прочитайте вопрос, потом код. Часто нужно лишь одно значение, и трассировать весь алгоритм не требуется.
  2. Ведите таблицу значений. Столбцы — переменные, строки — итерации. Это единственный надёжный способ не запутаться в циклах.
  3. Проверьте границы. Большинство ошибок в заданиях спрятаны в первом и последнем шаге цикла: 1 против 2, n против n−1.
  4. Подставьте вариант ответа. Для вопросов с пропуском быстрее проверить четыре варианта на маленьком примере, чем выводить логику в уме.

Типичные алгоритмы в заданиях

  • обход массива, поиск максимума и суммы;
  • двоичный поиск и линейный поиск;
  • сортировка пузырьком и вставками;
  • работа со стеком и очередью;
  • обход связного списка и дерева, рекурсия;
  • преобразование систем счисления и работа со строками.

Разбор самих алгоритмов — в темах «Структуры данных» и «Алгоритмы».
