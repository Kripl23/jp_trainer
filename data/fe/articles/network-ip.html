IP-адресация

IPv4 — 32 бита, записывается четырьмя октетами: 192.168.10.25. IPv6 — 128 бит, восемь групп по четыре шестнадцатеричные цифры; решает проблему исчерпания адресов и встроенно поддерживает IPsec.

Адрес делится на сетевую часть (ネットワークアドレス) и хостовую (ホストアドレス). Границу задаёт маска подсети (サブネットマスク), например 255.255.255.0 = префикс /24.

Расчёт подсети

Число адресов в подсети = 2^(32 − префикс) Число пригодных хостов = 2^(32 − префикс) − 2 (минус адрес сети и широковещательный адрес)

Пример. 192.168.10.0/26: 2⁶ = 64 адреса, из них 62 хоста. Адрес сети 192.168.10.0, широковещательный 192.168.10.63, хосты .1–.62. Следующая подсеть начинается с 192.168.10.64.

Приём: 256 − значение последнего октета маски = шаг подсетей. Для маски 255.255.255.192 шаг равен 64, значит границы подсетей — .0, .64, .128, .192.

Частные адреса не маршрутизируются в интернете; выход наружу даёт NAT (ネットワークアドレス変換) или NAPT/IP-маскарад, который дополнительно подменяет номера портов, позволяя многим хостам делить один внешний адрес.

Адрес 127.0.0.1 — петля (ループバック). Если хост получил адрес вида 169.254.x.x, значит DHCP-сервер не ответил (APIPA).

Маршрутизация

Маршрутизатор (ルータ) выбирает путь по таблице маршрутизации, сверяя адрес назначения с записями по самому длинному совпадающему префиксу. Шлюз по умолчанию (デフォルトゲートウェイ) — куда отправлять всё, для чего нет явного маршрута.

  • Статическая маршрутизация — маршруты заданы вручную;
  • Динамическая: RIP (по числу переходов, вектор расстояний), OSPF (по состоянию каналов, учитывает стоимость), BGP (между автономными системами).

ARP определяет MAC-адрес по IP-адресу в локальной сети, ICMP используется для служебных сообщений и команды ping.

Службы прикладного уровня

  • DNS — преобразует имена в адреса; записи A (IPv4), AAAA (IPv6), MX (почтовый сервер), CNAME (псевдоним), NS (сервер имён). Работает иерархически, с кэшированием;
  • DHCP — автоматически выдаёт клиентам адрес, маску, шлюз и DNS на время аренды (リース期間);
  • HTTP/HTTPS — запрос-ответ; HTTPS добавляет TLS. Коды ответов: 200 OK, 301 перемещено, 403 запрещено, 404 не найдено, 500 ошибка сервера;
  • Почта: SMTP отправляет, POP3 забирает письма на клиент, IMAP работает с почтой на сервере;
  • NTP — синхронизация времени, важна для журналов и сертификатов;
  • プロキシ — посредник для доступа в интернет: кэширует, фильтрует, скрывает внутренние адреса.

Качество и балансировка

QoS (サービス品質) управляет приоритетами трафика: голос вперёд, резервное копирование в фоне. ロードバランサ распределяет запросы между серверами по алгоритмам round robin, по числу соединений или по нагрузке; заодно даёт отказоустойчивость, исключая упавшие узлы.
