Оценка сложности

計算量 — как растёт время работы при росте объёма данных n. В O-нотации отбрасывают константы и младшие члены: 3n² + 5n + 7 = O(n²).

Поиск

  • Линейный поиск (線形探索) — перебор подряд, O(n). В среднем (n+1)/2 сравнений, в худшем n.
  • Двоичный поиск (2分探索) — только в отсортированном массиве, O(log n). Число сравнений в худшем случае — ⌈log₂(n+1)⌉.
  • Хеш-поиск (ハッシュ探索) — O(1) в среднем.
low ← 1;  high ← n
while (low ≤ high)
  mid ← (low + high) ÷ 2
  if (A[mid] = key)   return mid
  elseif (A[mid] < key) low ← mid + 1
  else                high ← mid − 1
  endif
endwhile

Устойчивость (安定性) — равные элементы сохраняют исходный взаимный порядок. Быстрая сортировка вырождается в O(n²) на уже отсортированных данных при неудачном выборе опорного элемента (ピボット).

Частый вопрос: «сколько обменов сделает пузырьковая сортировка на данном массиве». Считайте число инверсий — пар, стоящих в неправильном порядке; оно и равно числу обменов.

Рекурсия

再帰 — функция вызывает саму себя. Обязательны условие выхода (базовый случай) и уменьшение задачи. Классика: факториал, числа Фибоначчи, ханойские башни (ハノイの塔 — для n дисков нужно 2ⁿ−1 перемещений), обход дерева.

○整数型: fact(整数型: n)
  if (n ≤ 1)
    return 1
  endif
  return n × fact(n − 1)

Наивная рекурсия для Фибоначчи имеет сложность O(2ⁿ) из-за повторных вычислений; мемоизация или итерация сводят её к O(n).

Основные приёмы

  • Разделяй и властвуй (分割統治法) — разбить задачу, решить части, объединить: сортировка слиянием, двоичный поиск;
  • Динамическое программирование (動的計画法) — сохранять решения подзадач: задача о рюкзаке, кратчайшие пути;
  • Жадный алгоритм (貪欲法) — на каждом шаге выбирать локально лучший вариант; не всегда даёт оптимум;
  • Перебор с возвратом (バックトラック) — обход вариантов с откатом.

Графовые алгоритмы

  • Поиск в ширину (幅優先探索, BFS) — очередь, находит кратчайший путь по числу рёбер;
  • Поиск в глубину (深さ優先探索, DFS) — стек или рекурсия;
  • Алгоритм Дейкстры (ダイクストラ法) — кратчайшие пути во взвешенном графе с неотрицательными весами;
  • Алгоритмы Прима и Краскала — минимальное остовное дерево (最小全域木).

Что чаще всего спрашивают

  1. Трассировка фрагмента: какое значение примет переменная.
  2. Сравнение сложности двух подходов.
  3. Число сравнений или обменов при конкретных входных данных.
  4. Выбор структуры данных под задачу (например, очередь с приоритетом → куча).
