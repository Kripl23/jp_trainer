# jp_trainer

Два тренажёра в одном приложении:

1. **Японский по Wagotabi** — все уроки игры в порядке прохождения: объяснения,
   лексика, грамматика и тесты теми же типами заданий, что в игре (без сюжета).
2. **基本情報技術者試験 (FE)** — конспекты, японские термины и тесты по программе
   экзамена, всё на русском.

Статус материала — «знаю / учу / трудное» — ставите вы сами. Тесты его не меняют:
они лишь копят статистику попыток, которая показывается рядом как справка.

## Возможности

### Японская часть

- **86 уроков** в том порядке, в каком их даёт игра: префектура → локация →
  уроки локации → слова внутри урока.
- **519 слов**, 650 примеров предложений, 202 кандзи, 177 ключей, 95 таблиц
  спряжения, 131 грамматическая конструкция, 41 разбор-объяснение из игры.
- **Задания повторяют игровые**: значение слова, слово по значению, чтение
  (выбор и ввод), запись слова каной, частица в предложении, сборка предложения
  из блоков, форма спряжения, значение и чтение кандзи.
- Ввод каны — латиницей: `neko` превращается в `ねこ` (WanaKana, лежит локально).
- Фуригана выводится как `<ruby>` из тех же данных, что в игре (`分[わ]かる`).
- Прогресс: урок засчитывается при результате от 80%; главы показывают процент
  прохождения. Уроки не блокируются — открыть можно любой, «текущим» считается
  первый незавершённый.

### FE-экзамен

- **25 тем** в трёх областях (テクノロジ系 / マネジメント系 / ストラテジ系) плюс
  разбор формата экзамена и нотации псевдокода 擬似言語.
- **175 вопросов** с пояснением к каждому и **325 терминов**
  (японский, чтение, английский, русский).
- Два режима: тест по теме и тренировка терминов в обе стороны
  (японский → русский и обратно), можно ограничиться отмеченными.

## Установка

```bash
cd jp_trainer
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp example.env .env
.venv/bin/python scripts/seed.py    # заливка data/ в БД, идемпотентно
```

## Запуск

Dev:

```bash
./run.sh
```

Prod (supervisord внутри .venv, без рута):

```bash
.venv/bin/supervisord -c supervisord.conf
.venv/bin/supervisorctl -c supervisord.conf status
```

Логи — в `logs/`, порт задаётся в `.env` (по умолчанию 8040).

## Тесты

```bash
.venv/bin/python -m pytest test/
```

Кроме кода проверяется и содержимое `data/`: у каждой темы FE есть статья,
вопросы и термины; правильный ответ присутствует среди вариантов; блоки
предложений собираются ровно в исходное предложение.

## Структура

```
app/
  main.py                FastAPI, статика, роутеры
  db.py                  схема SQLite: справочники wg_*/fe_* + пользовательские таблицы
  services/
    quiz.py              генератор заданий и проверка ответов
    wagotabi_text.py     рендер игровой разметки (<word=…>, <style=Title1>, фуригана)
    marks.py             ручные отметки «знаю / учу / трудное»
    progress.py          прогресс по урокам и темам
    content.py           доступ к учебным данным
    checker.py           нормализация ответов (кана/кандзи, ё→е)
  routers/               pages (страницы), jp, fe, stats (API)
  templates/, static/    Jinja2 + vanilla JS
data/
  wagotabi/*.json        выгрузка из игры
  fe/topics.json         темы экзамена
  fe/articles/*.html     статьи
  fe/questions.json      вопросы
  fe/terms.json          термины
scripts/
  extract_wagotabi.py    выгрузка данных из установленной игры
  seed.py                заливка data/ в БД
```

## Откуда берутся данные Wagotabi

Игра сделана на Unity (Mono); учебные таблицы лежат в ScriptableObject'ах класса
`DictionaryData` внутри `Wagotabi_Data/data.unity3d`, а порядок уроков — в
`PrefectureData` → `LocationData._lessons`. Скрипт разбирает их, генерируя
typetree из игровых DLL:

```bash
.venv/bin/pip install -r requirements-extract.txt
.venv/bin/python scripts/extract_wagotabi.py --game "C:/.../steamapps/common/Wagotabi"
.venv/bin/python scripts/seed.py
```

Выгруженные JSON уже лежат в `data/wagotabi/`, так что для работы приложения
запускать извлечение не нужно — только при обновлении игры.

## Как пополнять материал FE

1. Добавьте тему в `data/fe/topics.json` (`id`, `order`, `area`, `title`, `summary`).
2. Положите статью в `data/fe/articles/<id>.html` — обычный HTML;
   доступны классы `.box` (врезка), `.formula` (формула), `.term` (японский термин).
3. Допишите вопросы в `questions.json` (правильный ответ обязан быть среди
   `options`) и термины в `terms.json`.
4. `.venv/bin/python scripts/seed.py` и `.venv/bin/python -m pytest test/test_data.py`.

## Заметки по данным

- 422 слова из 519 привязаны к урокам; остальные 97 (названия городов, лексика
  диалогов, заготовки неизданных глав) идут в конце с меткой «вне уроков».
- У 46 слов нет русского перевода, у 19 — вообще никакого: так в данных игры.
  В интерфейсе это показано явно, в задания «значение слова» такие записи не попадают.
- Служебные пометки переводчиков вида `(#IMPLIES_FAVOR)` вычищены при извлечении.
- Таблицы старой версии тренажёра (`words`, `srs_progress`, `review_log`) остались
  в БД нетронутыми, приложение их не использует; при желании их можно удалить.
